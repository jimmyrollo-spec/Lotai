# LotAI — working repository name

> **Status:** active build. `LotAI` is a temporary internal/product label, not the final public brand.

A property-specific residential project feasibility platform answering a narrower, more valuable question than generic zoning lookup:

**Can I build this specific project on this specific property?**

Initial product wedge:
- Detached garages / workshops
- Decks
- Sheds / accessory structures
- Pools
- Home additions

The product combines property/parcel context, jurisdiction rules, project parameters, constraints, source evidence, confidence, and next steps in a decision-grade interface.

## Build principles

1. Project-first, not parcel-first.
2. Every regulatory statement must be traceable to an authoritative source.
3. Never present uncertain interpretation as legal certainty.
4. Free results should be genuinely useful; paid reports add depth, auditability, and planning value.
5. SEO pages must contain unique jurisdiction/project data and never become thin doorway pages.
6. Brand, UI, and information density should feel like premium property intelligence—not a lead-gen site or AI wrapper.
7. ChatGPT-assisted development must preserve architecture and design decisions documented in this repository.

## Current phase

Phase 1: design system + public homepage + address/project intake + demo property feasibility workspace.

Live municipal/parcel/regulatory integrations are intentionally separated from the first UI vertical slice. Demo regulatory data must always be labeled as such until authoritative-source ingestion is active.
